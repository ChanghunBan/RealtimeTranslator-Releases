# 실시간 통역 (Realtime Translator)

회의·Teams·영상의 한국어 ↔ 영어 음성을 실시간으로 인식해 자막(또는 음성)으로 번역해 주는 Windows 프로그램입니다.
인터넷 없이 PC 안에서 동작합니다.

## 다운로드
**[최신 버전 받기](https://github.com/ChanghunBan/RealtimeTranslator-Releases/releases/latest)** → `RealtimeTranslator-Setup-x.y.z.exe`

## 설치
1. 설치 파일을 실행합니다. (관리자 권한 필요 없음)
2. 설치가 끝나면 시작 메뉴의 **실시간 통역**으로 실행합니다.
3. 새 버전이 나오면 프로그램이 시작할 때 업데이트할지 물어봅니다.

## 사용법
1. **마이크**(대면 회의·내 목소리) 또는 **PC 소리**(Teams·영상)를 선택합니다.
2. **▶ 시작**을 누르면 말하는 내용이 자막 창에 번역되어 나타납니다.
3. 자막 창은 드래그로 옮기고, 모서리로 크기를 조절하고, 마우스를 올리면 글자 크기를 바꿀 수 있습니다.

## 시스템 요구 사항
- Windows 10/11 64비트, 메모리 8GB 이상 권장
- 디스크 여유 공간 약 1.5GB
